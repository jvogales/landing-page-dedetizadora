# Dedetizadora Orlandini — Landing Page

Landing page institucional da **Dedetizadora Orlandini**, empresa de controle de pragas urbanas com atendimento residencial, comercial e industrial em Cornélio Procópio - PR.

> "Protegendo o que mais importa."

---

## 🎯 Objetivo

Apresentar os serviços da Dedetizadora Orlandini, transmitir confiança através de identidade visual profissional e converter visitantes em leads via WhatsApp.

---

## 🖼️ Identidade visual

| Elemento | Valor |
|---|---|
| Azul-marinho (primária) | `#0D1B3E` |
| Vermelho (destaque) | `#C81E2C` |
| Fundo claro | `#F4F5F7` |
| Tipografia | Poppins (700–900 para títulos) |
| Logo | Alvo de mira com inseto centralizado |

Os materiais gráficos (calendário de pragas, banners, posts) seguem o mesmo padrão visual e devem manter consistência com o site.

## 🧩 Seções da página

1. **Hero** — chamada principal + botão de WhatsApp
2. **Sobre** — apresentação da empresa e diferenciais
3. **Serviços** — pragas atendidas (formigas, cupins, baratas, ratos, escorpiões, aranhas, pulgas, carrapatos, mosquitos, traças)
4. **Calendário das Pragas Urbanas** — quando cada praga costuma aparecer com mais intensidade
5. **Diferenciais** — produtos certificados, atendimento residencial/comercial/industrial, atendimento rápido via WhatsApp
6. **Depoimentos** *(opcional)*
7. **Contato / CTA final** — telefone e WhatsApp

## 🚀 Como rodar localmente

```bash
git clone https://github.com/jvogales/dedetizadora-orlandini.git
cd dedetizadora-orlandini
# abrir index.html no navegador
# ou, se usar um servidor local:
npx serve .
```
